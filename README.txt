THE LAST SAVE
"Some memories should stay dead."

Made for THE WORST GAME WINS game jam.

--

HOW TO PLAY:
1. Extract the ZIP
2. Open the folder
3. Double-click "THE LAST SAVE.exe"
4. Play

No internet connection is required.
No installation is required.

--

CONTROLS:
  S           = Move Forward (We think)
  W           = Move Backward (?)
  D           = Turn Left (Maybe)
  A           = Turn Right (Probably)
  E           = Interact
  I           = Inventory
  F           = Flashlight
  SPACE       = Sprint
  ESC         = Pause

--

If the game asks you to do something terrible,
that is probably intentional.

If the controls feel wrong,
that is definitely intentional.

If the story makes you feel something,
that is what we were going for.
