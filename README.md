# THE LAST SAVE

> *"Some memories should stay dead."*

---

## About

**THE LAST SAVE** is a psychological horror / dark comedy game made for **THE WORST GAME WINS** game jam.

It tells the story of **Eli**, a former radio operator haunted by the death of his daughter **Maya** six years ago. One night, an impossible transmission arrives. A little girl's voice says: *"Dad?"*

What follows is a 15–25 minute journey through an abandoned town, a sealed research facility, and the fragile boundary between memory and identity.

The story is genuine.

The game design is intentionally terrible.

That is the point.

## How to Play

You play as Eli. You received a radio transmission from someone who should not be able to transmit anything.

Explore. Investigate. Find the source of the signal.

Do not trust the objective marker.

Do not trust the GPS.

You may trust the story.

## Features

- ✅ Original psychological horror narrative with two endings
- ✅ Multiple acts: the house, the town, the facility
- ✅ Unique NPC behavior profiles (8 types, no two behave the same)
- ✅ Intentionally terrible game design (as intended)

- ✅ Absurd inventory with questionable items
- ✅ Terrible GPS/objective system
- ✅ Horror atmosphere with sanity system
- ✅ Fully offline — no internet required

## For The Judge

### Running the Game

1. Extract the ZIP file
2. Open the `THE_LAST_SAVE_WINDOWS` folder
3. Double-click **THE LAST SAVE.exe**
4. Play

**No internet connection is required.**
**No Node.js is required.**
**No npm is required.**
**No Python is required.**
**No web server is required.**

Simply extract and double-click.

## Story Notes (No Spoilers)

Pay attention to:
- Photographs that seem slightly wrong
- Documents that mention Eli's name
- Computers that call him something unexpected
- Dates that don't quite add up
- Maya knowing things she shouldn't

Everything was intentional.
